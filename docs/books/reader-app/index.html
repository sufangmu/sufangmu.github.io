📖 使用帮助

📚 书架与分类

左侧树形菜单按分类展示所有书籍，点击分类可展开/收起，点击书名即可开始阅读。

📥 导入数据

导入之前通过「导出数据」功能备份的 JSON 文件，恢复阅读进度、标记笔记、书签和设置。

📤 导出数据

将当前所有阅读数据（阅读进度、标记笔记、书签、主题字体设置）导出为 JSON 文件，可用于备份或迁移。

📂 导入本地书籍

从电脑中选择 PDF 或 EPUB 文件导入到书架。支持拖拽文件到页面任意位置快速导入。导入的书籍会出现在「本地导入」分类中。

🗑 清除数据

删除浏览器中所有本地存储数据，包括标记笔记、书签、阅读进度、设置以及本地导入的书籍文件。此操作不可撤销！

🖊 标记与笔记

PDF：点击画笔按钮进入标记模式，可在页面上自由绘制；按住 Shift 可画直线。支持调整颜色和笔刷大小。
EPUB：选中文字即可高亮标记，点击高亮区域可添加笔记。

🔍 搜索

PDF：全文搜索，精确匹配计数。EPUB：浏览器查找，逐项导航。
快捷方式：点击工具栏 🔍 按钮或按 Ctrl+F。

⌨️ 快捷键

← → 翻页 · Ctrl+滚轮 缩放 · Ctrl+F 搜索

Esc 关闭目录 / 关闭搜索 · Enter 下一个 · Shift+Enter 上一个

🎨 主题

支持明亮、暗色、护眼、羊皮纸四种阅读主题，点击顶部工具栏的图标即可切换。
